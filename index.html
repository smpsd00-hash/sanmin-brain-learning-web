16 個單元教案

可依班級時間、學生需求與既有課程彈性調整。建議每單元 40 分鐘，也可拆成 2 次 20 分鐘。

Teacher Use

列印與使用

打開任一單元後，可直接使用「列印本單元」功能。瀏覽器會自動套用教師友善列印版面。

🖨️ 列印教案

在單元詳細頁按「列印本單元」，即可列印學習目標、教學流程與教師引導語。

✍️ 列印學習單

同一頁面往下即可看到學生學習單；建議 A4 直式列印，可直接發給學生。

📱 手機也能看

網站採響應式設計，教師可在教室用手機、平板或電腦快速查找單元。

🌐 GitHub + Netlify

純靜態網站，不需要後端。可直接上傳 GitHub repository，再在 Netlify 選擇 Import from Git。

Design Principles

設計理念

本資源把「認識自己的大腦」定位為一套全校共同語言，而不是額外增加的知識課。教師不需要成為腦科學專家，也能透過生活化情境、短活動與反思，陪學生逐步形成自我理解與自我調整能力。

01先經驗，再命名從孩子熟悉的生活經驗進入，而不是先講名詞。
02先練習，再評估讓學生實際嘗試策略，再討論哪一種方法適合自己。
03理解情緒，不壓抑情緒情緒是訊號；調節是為了更有能力做出選擇。
04逐步放手，走向自主從教師示範到學生自我監控與修正。
教師提醒：本網站為教育用途課程設計，不作醫療診斷或心理治療工具。若學生出現持續、明顯或影響日常功能的睡眠、情緒、注意力或壓力問題，仍應依學校輔導系統與專業資源進一步處理。
